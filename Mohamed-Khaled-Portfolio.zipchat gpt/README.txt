# Mohamed Khaled — Personal Portfolio

A premium responsive personal portfolio for a Web Designer, built with HTML5, CSS3 and JavaScript.

## Files
- index.html
- style.css
- script.js

## Easy edits
1. Profile photo: edit the `.profile-img` image URL in `index.html`.
2. Social links: replace each `href="#"` with your real URL.
3. Email: replace `your@email.com`.
4. WhatsApp: replace the `wa.me` number and displayed number.
5. Projects: duplicate/edit project cards in the Projects section.
6. Bio/name/title: edit the text directly in `index.html`.

## Run
Open `index.html` in a browser, or use VS Code + Live Server.

## Note
The contact form is front-end only. Connect it to an email/form backend before publishing.
